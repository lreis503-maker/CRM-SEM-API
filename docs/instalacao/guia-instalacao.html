Guia de instalação do CRM

Passo a passo completo, do zero. Você não precisa saber programar — é tudo copiar, colar e clicar.

Antes de começar

Reserve cerca de 40 minutos. Você vai criar três contas gratuitas:

Serviço Para quê Endereço
GitHub guarda o código github.com
Supabase o banco de dados supabase.com
Railway coloca o site no ar railway.app
Sobre pagamento GitHub e Supabase têm plano gratuito que basta para começar. O Railway costuma pedir um cartão de crédito para liberar a publicação — confira os valores no site deles antes de continuar.
Deixe um bloco de notas aberto Ao longo do caminho você vai copiar 5 valores. Cole cada um no bloco de notas assim que aparecer: alguns só são exibidos uma vez, e ficar voltando atrás é o que mais atrasa essa instalação.
Anote aqui enquanto avança:
1. Senha do banco Supabase:
2. Project URL:
3. Chave anon public:
4. Chave service_role:
5. Chave de criptografia (64 caracteres):
6. Endereço do site no Railway:

Parte 1 — Pegar o código no GitHub (5 min)

  1. Entre em github.com e clique em Sign up. Use seu e-mail e crie uma senha.
  2. Confirme o e-mail que o GitHub enviar.
  3. Peça para quem te passou este guia dar acesso ao repositório do CRM. Você vai receber um convite por e-mail — aceite.
  4. Abra o repositório e confirme que consegue ver os arquivos.
Quer sua própria cópia? No repositório, clique em Fork (canto superior direito). Isso cria uma cópia na sua conta, que você controla sozinho.

Parte 2 — Criar o banco no Supabase (10 min)

  1. Entre em supabase.com e clique em Start your project.
  2. Escolha Continue with GitHub e autorize.
  3. Clique em New project.
  4. Preencha:
    • Name: crm
    • Database Password: clique em Generate a password e copie para o bloco de notas (valor 1). Ela não é mostrada de novo.
    • Region: South America (São Paulo) — o mais perto do Brasil, deixa o sistema mais rápido.
  5. Clique em Create new project e espere cerca de 2 minutos.

Parte 3 — Criar as tabelas (10 min)

O banco nasce vazio. Agora você vai colar 4 arquivos de SQL que criam tudo: tabelas, permissões e pastas de arquivos.

Os arquivos estão no repositório, na pasta:

supabase/instalacao/

São estes quatro, nesta ordem:

parte-1-de-4.sql
parte-2-de-4.sql
parte-3-de-4.sql
parte-4-de-4.sql

Como colar cada um

  1. No Supabase, menu da esquerda → SQL Editor.
  2. Clique em New query.
  3. Abra o arquivo parte-1-de-4.sql no GitHub e clique no botão Copy raw file (ícone de duas folhas, no topo do arquivo).
  4. Volte ao Supabase, clique na área de texto e cole (Ctrl+V).
  5. Clique em Run (ou Ctrl+Enter).
  6. Espere aparecer Success na parte de baixo.
  7. Apague tudo (Ctrl+A, depois Delete) e repita com a parte 2, depois a 3, depois a 4.
Se der erro em alguma parte, pare Não pule para a próxima. Tire uma foto da mensagem de erro e mande para quem te passou este guia. Rodar as partes fora de ordem cria um banco pela metade, e o site não vai funcionar direito.
Rodou duas vezes sem querer? Não tem problema. Esses arquivos podem ser executados de novo sem apagar nada nem duplicar nada. Na dúvida, volte para a parte 1 e rode as quatro na ordem.

Parte 4 — Copiar as 3 chaves do Supabase (3 min)

  1. No Supabase, clique na engrenagem (Project Settings), no canto inferior esquerdo.
  2. Clique em API (em alguns projetos aparece como API Keys).
  3. Copie os três valores para o bloco de notas:
O que copiar Vira a variável
Project URL
(começa com https://) 		NEXT_PUBLIC_SUPABASE_URL
anon public NEXT_PUBLIC_SUPABASE_ANON_KEY
service_role secret SUPABASE_SERVICE_ROLE_KEY
A chave service_role é secreta Ela dá acesso total ao banco, ignorando todas as permissões. Nunca mande por WhatsApp, nunca poste em grupo, nunca coloque num print. Ela só vai para o painel do Railway, na Parte 7.

Parte 5 — Gerar a chave de criptografia (2 min)

O CRM guarda as senhas do WhatsApp criptografadas. Para isso ele precisa de uma chave só sua, com 64 caracteres.

No Windows, abra o PowerShell (tecla Windows, digite powershell, Enter) e cole esta linha inteira: 

$b = New-Object byte[] 32
[System.Security.Cryptography.RandomNumberGenerator]::Create().GetBytes($b)
($b | ForEach-Object { $_.ToString('x2') }) -join ''

Vai aparecer uma sequência de 64 letras e números. Copie para o bloco de notas (valor 5).

Guarde essa chave Se você trocá-la depois, todas as conexões de WhatsApp param de funcionar e precisam ser refeitas. Não use uma chave que alguém te passou: ela tem que ser gerada por você.

Parte 6 — Publicar no Railway (8 min)

  1. Entre em railway.app e clique em Login → GitHub.
  2. Clique em New Project.
  3. Escolha Deploy from GitHub repo.
  4. Selecione o repositório do CRM. Se ele não aparecer, clique em Configure GitHub App e libere o acesso.
  5. O Railway vai tentar publicar e vai falhar. Isso é esperado — as variáveis ainda não existem.

Escolher a versão certa do código

  1. Clique no serviço que apareceu → aba Settings.
  2. Procure Source → Branch.
  3. Selecione: feat/uazapi-whatsapp-provider
Esse passo é fácil de esquecer A conexão do WhatsApp por QR Code está nessa versão do código. Se ficar na main, o site sobe normalmente mas a opção de QR Code simplesmente não aparece na tela — sem nenhuma mensagem explicando por quê. Confirme antes de seguir.

Parte 7 — Colocar as variáveis (5 min)

No serviço do Railway, abra a aba Variables e clique em New Variable para cada linha:

Nome Valor
NEXT_PUBLIC_SUPABASE_URL valor 2 do bloco de notas
NEXT_PUBLIC_SUPABASE_ANON_KEY valor 3
SUPABASE_SERVICE_ROLE_KEY valor 4
ENCRYPTION_KEY valor 5 (os 64 caracteres)
NEXT_PUBLIC_APP_LOCALE pt-BR

Falta ainda o NEXT_PUBLIC_SITE_URL, que só existe depois da próxima parte.

Parte 8 — Gerar o endereço do site (3 min)

  1. Aba Settings → seção Networking.
  2. Clique em Generate Domain.
  3. Vai aparecer um endereço parecido com seu-projeto.up.railway.app. Copie (valor 6).
  4. Volte em Variables e crie a última: 
    NEXT_PUBLIC_SITE_URL = https://seu-projeto.up.railway.app
  5. Clique em Deploy (ou Redeploy) e espere o build terminar — uns 3 a 5 minutos.
O erro mais comum desta instalação inteira O NEXT_PUBLIC_SITE_URL precisa começar com https:// e não pode terminar com barra.

Certo: https://meu-crm.up.railway.app
Errado: meu-crm.up.railway.app (falta o https)
Errado: https://meu-crm.up.railway.app/ (barra no fim)

Se errar, o site abre normalmente e parece funcionar — mas o WhatsApp nunca recebe mensagem nenhuma, e não aparece erro em lugar nenhum.

Parte 9 — Avisar o Supabase qual é o endereço (2 min)

O Supabase envia o e-mail de confirmação de cadastro com um link. Ele precisa saber para onde esse link aponta.

  1. No Supabase, menu da esquerda → Authentication.
  2. Clique em URL Configuration.
  3. Em Site URL, coloque o endereço do Railway (valor 6), do mesmo jeito: com https:// e sem barra no fim.
  4. Clique em Save.

Parte 10 — Criar seu usuário (3 min)

  1. Abra o endereço do Railway no navegador.
  2. Clique em Criar conta.
  3. Preencha nome, e-mail e senha.
  4. Abra seu e-mail e clique no link de confirmação.
  5. Volte ao site e entre com e-mail e senha.

Pronto — o CRM está funcionando.

O e-mail não chegou? Olhe o spam. O Supabase limita quantos e-mails envia por hora no plano gratuito, então espere alguns minutos antes de tentar de novo.

Parte 11 — Ligar o WhatsApp por QR Code (opcional, 10 min)

Esta parte é opcional e depende de uma conta na UAZAPI, que é um serviço pago à parte. Sem ela, o CRM funciona normalmente — só não conecta o WhatsApp por QR Code.

  1. Crie sua conta no painel da UAZAPI e copie o token de administrador da instalação.
  2. No Railway, aba Variables, acrescente três variáveis:
Nome Valor
UAZAPI_ENABLED true
UAZAPI_BASE_URL o endereço da sua UAZAPI, com https://
UAZAPI_ADMIN_TOKEN o token de administrador
  1. Clique em Redeploy e espere terminar.
  2. No CRM, vá em Configurações → WhatsApp.
  3. Escolha Conexão por QR Code e clique em Conectar.
  4. No celular: WhatsApp → Aparelhos conectados → Conectar aparelho → leia o código da tela.
  5. Quando aparecer Conectado, clique em Baixar histórico para trazer as conversas que já existem no celular.
O token de administrador é secreto Ele controla a instalação inteira da UAZAPI, não só a sua conta. Trate com o mesmo cuidado da chave service_role: nada de print, nada de grupo de WhatsApp.

Deu problema? Comece por aqui

O que você vê Causa provável O que fazer
O build do Railway falha falta alguma variável Confira as 6 variáveis da Parte 7 e 8, letra por letra. Depois Redeploy.
Site abre mas dá erro ao entrar SQL não rodou inteiro Volte à Parte 3 e rode as 4 partes na ordem.
E-mail de confirmação não chega limite do plano gratuito Olhe o spam e espere alguns minutos.
Link do e-mail leva para o lugar errado Site URL não configurada Refaça a Parte 9.
A opção de QR Code aparece apagada faltam as variáveis da UAZAPI, ou branch errada Confira a Parte 11 e a branch na Parte 6.
Conectou, mas não chega mensagem NEXT_PUBLIC_SITE_URL errada Confira o https:// e a barra no fim (Parte 8). Corrija, Redeploy e reconecte.
Mensagem de grupo não aparece conexão feita numa versão antiga Configurações → WhatsApp → Sincronizar configurações.
